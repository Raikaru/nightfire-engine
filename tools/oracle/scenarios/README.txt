Input scenarios for tools/oracle/trace.py --script (Skyrail multiplayer arena, savestate slot 2).
Line format: "<frame offset from the first recorded frame> <vpad command>".
vpad button names are DS2 labels (square = Square, triangle = Triangle, cross, circle, start, l1, r1;
L2 is "trig LT 1"). (Before 2026-10-02 square/triangle were swapped by an evdev BTN_NORTH/BTN_WEST mixup;
old traces are unaffected — they record the pad the game saw.)
